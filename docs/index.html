flowguard

Line-based static security linter for GitHub Actions workflows.

View the sample review report Source on GitHub

What it catches

  • Actions referenced by mutable tags instead of a pinned commit SHA
  • pull_request_target checking out PR code with elevated secrets
  • Untrusted github.event.* text interpolated into run: scripts
  • permissions: write-all and hardcoded credentials in env:
  • curl … | bash and checkout token persistence

Zero runtime dependencies. Human, JSON, and SARIF output. GitHub Action ready.

The sample report is generated from a synthetic fixture by a real flowguard scan — not invented findings. flowguard is a line-based heuristic, not a YAML parser; see the scope and non-claims.
